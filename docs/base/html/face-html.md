# HTML高阶

## defer

defer 属性是一个布尔属性。

如果设置了 defer 属性，则指定脚本在解析页面的同时并行下载，并在页面解析完成后执行。

注意：defer 属性仅适用于外部脚本（只有存在 src 属性 时才应使用）。

可以通过多种方式执行外部脚本：

如果已设置 async：脚本会在解析页面的同时并行下载，并在可用时立即执行（在解析完成之前）
如果已设置 defer（而未设置 async）：脚本会在解析页面的同时并行下载，并在页面解析完成后执行
如果既没有 async 也没有 defer：脚本被立即下载并执行，阻塞页面解析，直到脚本下载执行完毕

```html
<script src="demo_defer.js" defer></script>
```

## JS运行时

js 运行时集成了引擎，不同于引擎只负责执行代码逻辑，运行时还包括任务管理、调用操作系统能力、提供其他 api 等功能。简单来说 ：运行时=引擎+扩展能力

典型运行时案例：

- 浏览器：V8+WebAPI+渲染引擎
- 快应用引擎：V8+原生渲染+Java接口
- Node.js：V8+libuv+Native模块
  libuv 是一个高性能的异步非阻塞、跨平台的事件驱动 IO 库。是 nodejs 事件循环的底层实现。
