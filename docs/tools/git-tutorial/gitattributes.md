# Git 属性配置

[[TOC]]

`.gitattributes` 文件是一个文本文件，它可以指定文件的属性。这些属性可以用来控制文件的行为，比如文件的编码、换行符等。

常见的 `.gitattributes` 文件配置可以参考 [gitattributes/gitattributes](https://github.com/gitattributes/gitattributes) 项目。例如，使用 [`Web.gitattributes`](https://github.com/gitattributes/gitattributes/blob/master/Web.gitattributes) 配置任何 Web 项目。
