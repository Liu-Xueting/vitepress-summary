# 着色器的基础知识

GLSL（OpenGL Shading Language）是用于编写着色器的语言。着色器是运行在 GPU 上的小程序，用于处理图形渲染中的各种任务，如顶点处理、片段处理等。

## 3.1 着色器的类型

一个着色器就是绘制东西到屏幕上的函数，着色器有 `顶点着色器` 和 `片段着色器` 两种类型。

- `顶点着色器` : 处理每个顶点的属性，如位置、颜色等。它的主要任务是将顶点从对象坐标系转换到屏幕坐标系，并传递其他顶点属性给片段着色器。
- `片段着色器` : 处理每个像素的颜色。它接收来自顶点着色器插值的数据，并最终决定每个像素的颜色。

## 3.2 着色器的语法

在HTML中，如果你想把着色器代码直接写在 `<script>` 标签中，通常会使用自定义的MIME类型，以避免浏览器将其作为常规JavaScript代码执行。常见的做法是将type属性设置为一个非标准类型，例如x-shader/x-vertex和x-shader/x-fragment,分别用于顶点着色器和片段着色器。这样做的好处是可以通过JavaScript获取和解析着色器代码。

```html
<!--顶点着色器-->
<script id="vertex-shader" type="x-shader/x-vertex"></script>
<!--片段着色器-->
<script id="fragment-shader" type="x-shader/x-fragment"></script>
```

数据类型：

- 基本数据类型：`float`, `int`, `bool`,
- 向量类型：`vec2`, `vec3`, `vec4`（分别表示2D、3D和4D向量）
- 矩阵类型：`mat2`, `mat3`, `mat4`
- 采样器类型：`sampler2D`, `samplerCube`（用于纹理采样）

变量修饰符：

用于指定变量的作用域、生命周期和用途。不同的修饰符在顶点着色器和片段着色器中起到不同的作用。

- `attribute`：用于顶点着色器，定义从顶点缓冲区传入的变量（仅在顶点着色器中使用）
- `uniform`：用于顶点和片段着色器，定义全局变量，可以在多个渲染调用中保持不变，常用于传递变换矩阵、光照参数等。
- `varying`：用于顶点着色器和片段着色器之间传递数据，顶点着色器中的 `varying` 变量会被插值后传递给片段着色器。

内置变量:

- 顶点着色器内置变量：
  - `gl_Position`：必须设置的变量，表示顶点在裁剪空间中的位置。
  - `gl_PointSize`：用于控制点精灵的大小。
- 片段着色器内置变量：
  - `gl_FragColor`：必须设置的变量，表示片段的颜色

函数：

- 常用数学函数：`sin`, `cos`, `tan`, `sqrt`, `length`, `normalize`, `pow`, `exp`, `log`, `abs`, `min`, `max`, `clamp`
- 向量函数：`dot`, `cross`, `mix`, `step`, `smoothstep`, `normalize`, `length`, `distance`
- 纹理采样函数：
  - `texture2D(sampler, texCoords)`：用于在片段着色器中采样2D纹理。
  - `textureCube(sampler, texCoords)`：用于在片段着色器中采样立方体纹理。

定义精度：

在着色器中，可以使用 `precision` 关键字来定义浮点数的精度。常见的精度有

- `highp`（高精度）：通常用32位表示，适用于需要高精度计算的场景，如顶点位置计算，复杂的物理效果等。
- `mediump`（中等精度）：通常用16位表示，适用于大多数片段着色器计算，如颜色插值、纹理采样等。
- `lowp`（低精度）：通常用8位表示，适用于对精度要求不高的场景，如某些颜色处理或简单的效果。

```glsl
precision mediump float; // 定义中等精度的浮点数
```

主函数：着色器必须要有一个主函数 `void main()`，这是着色器执行的入口点。

```glsl
void main() {
    // 着色器代码
}
```
