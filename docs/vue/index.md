## 项目创建方式

### Vite 创建

```bash
npm create vite@latest my-vue-app --template vue
cd my-vue-app
npm install
npm run dev
```

### Vue 创建

这种方式创建出来的项目比较全面

```bash
pnpm create vue@latest
cd <your-project-name>
pnpm install
pnpm run dev
```

### Vue CLI 创建

```bash
npm install -g @vue/cli
vue create my-vue-app
cd my-vue-app
npm run serve
```
